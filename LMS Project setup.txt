how to start:

1) Go to project folder:
	cd ~/development/learning_people/projects/lms_project

2) Activate virtual environment:
	source venv/bin/activate

3) Start the Django development server inside the actual project folder(lms) where manager.py is:
	cd ~/development/learning_people/projects/lms_project/backend
	python manage.py runserver
